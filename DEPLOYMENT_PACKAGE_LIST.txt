## Verification After Upload

1. Check all files uploaded:
   ls -la ~/jewellery_site/

2. Verify directory structure:
   tree ~/jewellery_site/ -L 2

3. Check file permissions:
   find ~/jewellery_site/ -type d -exec chmod 755 {} \;
   find ~/jewellery_site/ -type f -exec chmod 644 {} \;

4. Verify Python files:
   python -m py_compile jewellery_site/settings.py
